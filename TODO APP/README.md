📝 Todo App – TaskFlow

A simple and interactive Todo App built using HTML, CSS, and JavaScript to manage daily tasks and improve productivity.

🚀 Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Filter tasks by All Tasks, Today, Upcoming, and Completed
- Save tasks using Local Storage
- Tasks remain saved after refreshing the browser

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
